## فارسی

دو روش اتصال تازه به صفحهٔ اتصال اضافه شد: **ورکر کلادفلر** و **پروفایل‌های پروکسی**.

- **ورکر کلادفلر:** ساخت، به‌روزرسانی و حذف Worker یا Pages شخصی از داخل برنامه با توکن API. اتصال مستقل VLESS با حالت‌های Normal، Fragment و Browser Dialer، دامنهٔ سفارشی، آدرس‌های تمیز و آمار مصرف.
- سایت‌های پشت کلادفلر از طریق Proxy IP خودتان و در صورت نبود آن از درگاه‌های عمومی NAT64 باز می‌شوند. این درگاه‌ها نشانی مقصد را می‌بینند ولی محتوای رمزشده را نه.
- **پروفایل‌های پروکسی:** اتصال مستقیم با پروفایل‌های واردشدهٔ VLESS، VMess، Trojan و Shadowsocks. پیش از نمایش «متصل»، یک درخواست واقعی از نود انتخاب‌شده عبور داده می‌شود.
- **مسیریابی:** انتخاب خودکار نود خروجی و قواعد اختیاری برای شبکهٔ محلی، دامنه‌های ‎`.ir` و ردیاب‌های رایج. سایفون از UDP هم پشتیبانی می‌کند.
- چیدمان مرتب‌تر فیلدهای صفحهٔ ورکر.

اگر Worker را با نسخهٔ پیش‌انتشار ساخته‌اید، از صفحهٔ ورکر آن را به‌روزرسانی کنید تا اسکریپت جدید روی کلادفلر قرار بگیرد. نصب روی نسخهٔ پایدار قبلی، تنظیمات و Identity را نگه می‌دارد. حداقل نسخهٔ پشتیبانی‌شده Android 8 است.

## English

Add two connection methods on Connect: **Cloudflare Worker** and **Proxy profiles**.

- **Cloudflare Worker:** create, update and delete a personal Worker or Pages deployment from the app with an API token. Connect over standalone VLESS in Normal, Fragment or Browser Dialer mode, with custom domains, clean addresses and usage statistics.
- Reach Cloudflare-hosted sites through your own Proxy IP, or through public NAT64 gateways when none is set. The gateways see destination addresses, not encrypted content.
- **Proxy profiles:** connect directly with imported VLESS, VMess, Trojan and Shadowsocks profiles. A real request must pass through the selected node before the app reports connected.
- **Routing:** automatic exit-node selection and optional rules for the local network, `.ir` domains and common trackers. Psiphon also carries UDP.
- Tidier fields on the Worker screen.

If you created a Worker with the pre-release, update it from the Worker screen to deploy the new script. Upgrading the existing stable installation retains settings and Identity. Android 8 and later remain supported.
