## فارسی

اسکنر جدید اندپوینت اکنون بخشی از **اتصال خودکار و اتصال مجدد Aether** است. برنامه مسیرهای H2/H3 و تنظیمات بازیابی TLS را بررسی می‌کند، ترافیک واقعی را از مسیر پیدا‌شده عبور می‌دهد و همان آدرس و تنظیمات موفق را برای اتصال استفاده می‌کند.

- مسیرهای موفق هر شبکه ذخیره و در اتصال بعدی دوباره بررسی می‌شوند. با تغییر شبکه، نتیجهٔ جست‌وجوی قبلی کنار گذاشته می‌شود.
- پاسخ ثبت کلید MASQUE و به‌روزرسانی دستگاه اکنون آدرس داخلی و اندپوینت Identity را با هم به‌روز می‌کنند؛ اسکن با آدرس داخلی قدیمی انجام نمی‌شود.
- ثبت‌نام و صدور گواهی در برابر توقف و ری‌استارت مقاوم‌تر شده‌اند: تلاش ثبت‌نام پیش از ارسال ذخیره می‌شود و ثبت کلید نیمه‌تمام با همان کلید ادامه پیدا می‌کند.
- پاسخ 429 و زمان کامل انتظار Cloudflare رعایت می‌شود؛ درخواست ثبت‌نام پشت‌سرهم تکرار نمی‌شود.
- جزئیات اسکن خطاهای گواهی، هویت، ECH، پروتکل و عبور ترافیک را جدا نشان می‌دهند. رد شدن گواهی دیگر به‌اشتباه «تونل باز شد ولی داده عبور نکرد» نمایش داده نمی‌شود.
- بهبود راه‌اندازی ثبت‌نام با رقابت TLS مستقیم، Split ClientHello و ECH و اصلاح پشتهٔ تردهای موتور بومی از نسخهٔ آزمایشی قبلی وارد نسخهٔ پایدار شده است. اعتبارسنجی گواهی و پین‌های MASQUE فعال مانده‌اند.

**نصب:** نسخهٔ پایدار را روی نسخهٔ پایدار قبلی نصب کنید تا Identity حفظ شود. نسخه‌های آزمایشی محلی با شناسهٔ `.preview` برنامه‌ای جدا هستند؛ برای انتقال هویت آن‌ها به Stable، از پشتیبان هویت در تنظیمات استفاده کنید. برای گوشی‌های جدید، فایل `arm64-v8a` مناسب است.

**آزمون‌ها:** ۸۰۵ آزمون محلی اپ و موتور موفق شدند. با یک Identity آزمایشی مستقل، ثبت‌نام، ثبت کلید MASQUE، اسکن و آماده‌سازی موتور و درخواست وب واقعی روی H2 و H3 در محیط تست ویندوز موفق بود؛ اجرای مجدد نیز همان هویت ذخیره‌شده را استفاده کرد. آزمون میدانی روی همهٔ گوشی‌ها و اپراتورها کامل نشده و این نتایج تضمین اتصال روی هر شبکه نیستند.

## English

Integrate advanced endpoint discovery into **Automatic and Aether reconnects**. The app tries H2/H3 and TLS recovery profiles, verifies real traffic, and connects with the selected endpoint's exact configuration.

- Recheck remembered routes on their original network and discard pending selection when the network changes.
- Apply and persist the tunnel addresses and assigned edge returned by MASQUE key enrollment and device refresh.
- Persist registration attempts before sending and retain pending enrollment keys across interruption/restart.
- Honor the complete Cloudflare Retry-After and return HTTP 429 without repeatedly submitting the registration.
- Preserve specific TLS, certificate, ECH, protocol and traffic failures in scan details and diagnostics.
- Include the earlier adaptive API bootstrap and owned native-stack fixes, retaining authenticated TLS and MASQUE certificate pins.

Upgrade an existing stable installation to retain its Identity. Local `.preview` builds have a separate package; use Identity backup/import to transfer their credentials. Choose `arm64-v8a` for most current phones. Verify downloaded files against `SHA256SUMS`.

Validation: 312 Android unit tests and 493 native engine tests passed locally; five external-service tests remained ignored. An explicitly authorized independent live Identity passed registration, MASQUE enrollment, pinned H2/H3, embedded discovery/preparation, independent tunneled HTTP checks and reuse after process restart. Live tests ran on a Windows host; physical-device and affected-carrier acceptance remains incomplete. The release workflow repeats native/Android tests, release lint, signed builds and artifact verification before publishing.
