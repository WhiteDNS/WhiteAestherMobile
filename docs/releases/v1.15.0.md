## فارسی

هستهٔ Aether به **2.4.0** ارتقا یافت و کارت حالت پروکسی در صفحهٔ اتصال مرتب‌تر شد.

- بهبود دریافت Identity با مسیرهای تازهٔ API، فعال‌سازی WARP و ادامهٔ عملیات نیمه‌تمام با همان کلید؛ حفظ تنظیمات و Identityهای قبلی.
- به‌روزرسانی gatewayهای اسکن، pin گواهی و BoringSSL؛ گزینه‌های تازهٔ نام سرور و TLS در تنظیمات پیشرفته.
- کارت پروکسی با توضیح کوتاه، آدرس مستقل SOCKS5 و دکمهٔ کپی؛ چیدمان سازگار با فارسی، متن بزرگ و صفحه‌های کوچک.
- حفظ پشتیبانی از Android 8 و بالاتر.

نصب نسخهٔ جدید روی نسخهٔ پایدار قبلی، تنظیمات و Identity را نگه می‌دارد. اتصال نسخهٔ آزمایشی توسط کاربر تأیید شده است؛ پوشش همهٔ دستگاه‌ها و شبکه‌های محدود همچنان به آزمون میدانی نیاز دارد.

## English

Upgrade the Android Aether core to **2.4.0** and improve the Proxy card on Connect.

- Improve Identity provisioning with new API routes, WARP activation and resumable operations that retain the same key and existing identities.
- Update scanner gateways, certificate pins and BoringSSL, with new server-name and TLS controls in advanced settings.
- Replace the Proxy warning box with a compact explanation, a separate SOCKS5 address and a copy button; support Persian, larger text and narrow screens.
- Retain Android 8 and later support.

Upgrade the existing stable installation to retain settings and Identity. The user confirmed connectivity with the preview; comprehensive device and restricted-network acceptance remains separate from automated checks.
