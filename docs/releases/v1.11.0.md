# WhiteAestherMobile v1.11.0

## Connection recovery

- Adds Cloudflare WARP WireGuard over MASQUE (WOM), including use as the Aether hop in a carrier sequence.
- Automatic reaches alternative routes sooner and tries additional H2 handshake presets, IPv6 discovery where enabled, and WOM before deeper searches.
- Remembers the complete successful recovery profile and tries saved assigned endpoints before waiting for an API refresh.

## Custom TLS controls

- Traffic → Advanced now offers Automatic, Records, Compact, and Custom handshake splitting, including fragment size, delay, and server-name splitting.
- ECH offers automatic discovery or a custom Base64 ECHConfigList. Manual overrides survive recovery attempts, and changing ECH configuration updates the cache immediately.

## Failed connections and profile changes

- Closes pending VPN interfaces on failed or cancelled startup.
- Prevents old engine cleanup from interrupting a new profile and waits for stopped native carrier runs before replacement.
- Rejects an empty exit-node chain before starting the VPN instead of repeatedly retrying it. Routes → Use carriers only keeps Aether + Psiphon without requiring a node subscription.

Splitting applies to H2, including Android WOM's outer tunnel. ECH currently applies to H3. Direct WOM TUN mode uses IPv4 and MTU 1200.

Local validation: 686 tests passed, Android and Rust lint passed, and all three ABI builds and preview APK signatures were verified. Six external-network tests were left disabled. Physical-device and affected-operator validation was unavailable; no population-wide connection success rate is claimed.

Install the APK for your processor, or use the universal APK if unsure. SHA256SUMS covers the published APKs and Android App Bundle.
