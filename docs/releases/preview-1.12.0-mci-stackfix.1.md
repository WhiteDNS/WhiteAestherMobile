# نسخهٔ آزمایشی اتصال همراه اول و اصلاح کرش بومی

این Pre-release برای آزمایش بهبود اتصال روی اپراتورهایی مثل **همراه اول** تهیه شده است؛ مخصوص کسانی که نسخهٔ فعلی برایشان وصل نمی‌شود یا هنگام زدن Connect کرش می‌کند.

**اگر با نسخهٔ فعلی مشکل اتصال ندارید، فعلاً آپدیت نکنید.** پایداری این تغییرات روی همهٔ شبکه‌ها و گوشی‌ها هنوز به آزمون میدانی نیاز دارد.

## تغییرات

- شروع اتصال خودکار با MASQUE روی HTTP/2 در شبکه‌هایی که هنوز مسیر موفقی برایشان ذخیره نشده است؛ SNI تونل `www.cloudflare.com` است.
- بررسی چند رنج Cloudflare، شامل `188.114.97.6`، و رقابت TLS مستقیم، Split ClientHello و ECH برای دریافت هویت. فقط مسیر برنده درخواست ثبت‌نام را ارسال می‌کند؛ اعتبارسنجی گواهی حفظ شده است.
- اجرای آماده‌سازی و تونل روی ترد بومی جدا با استک ۸ مگابایتی؛ افزایش استک تردهای Tokio و انتقال Futureهای بزرگ و بافر پاسخ API به heap برای کاهش احتمال سرریز استک.

## نصب و گزارش تست

APKهای این انتشار در **GitHub Actions** از سورس تگ انتشار ساخته می‌شوند و با کلید رسمی انتشار امضا می‌شوند. این فایل‌ها روی نسخهٔ اصلی نصب می‌شوند؛ نسخهٔ داخل برنامه `1.12.0-mci-stackfix.1` است.

- `WhiteAestherMobile-1.12.0-mci-stackfix.1-arm64-v8a.apk`: برای گوشی‌های ARM64، از جمله Poco X7 Pro.
- `WhiteAestherMobile-1.12.0-mci-stackfix.1-armeabi-v7a.apk`: برای گوشی‌های ۳۲بیتی ARMv7.
- `WhiteAestherMobile-1.12.0-mci-stackfix.1-x86_64.apk`: برای شبیه‌سازهای x86_64، مانند LDPlayer.
- `WhiteAestherMobile-1.12.0-mci-stackfix.1-universal.apk`: شامل هر سه معماری.
- `WhiteAestherMobile-1.12.0-mci-stackfix.1-bundle.aab`: باندل اندروید برای توزیع در فروشگاه.
- `SHA256SUMS`: هش فایل‌های APK و AAB.

تست استک کوچک، تست‌های پل بومی و HTTPS/دریافت هویت، و بررسی امضا و وابستگی‌های APK انجام شده‌اند. رفع کرش روی خود Poco و موفقیت اتصال روی همراه اول هنوز به گزارش کاربران نیاز دارد. لاگ ارسالی LDPlayer همچنین خطاهای جداگانهٔ SIGILL برای Snowflake/Lyrebird داشت.

لطفاً نام اپراتور، مدل گوشی، نسخهٔ اندروید و نتیجهٔ اتصال را گزارش کنید؛ اگر کرش رخ داد، لاگ کرش را هم بفرستید.

این انتشار Pre-release است و به‌عنوان آپدیت پایدار پیشنهاد نمی‌شود.
