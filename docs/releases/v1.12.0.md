## فارسی

هستهٔ Aether به **2.3.0** ارتقا یافت. ECH اکنون روی H2 و H3، ثبت‌نام WARP و تونل بیرونی WireGuard over MASQUE پشتیبانی می‌شود؛ اتصال خودکار نیز می‌تواند H2 همراه ECH را امتحان کند.

- تنظیم حل‌کننده و دامنهٔ کلید ECH، رمزهای TLS 1.2، گروه‌های تبادل کلید، GREASE و آدرس ثبت‌نام WARP در بخش پیشرفتهٔ Traffic در دسترس‌اند. برای استفادهٔ عادی، کادرها خالی و Disable GREASE بدون تیک بماند.
- حالت جست‌وجوی **Verified edges**، نگهداری هشت سابقهٔ گیت‌وی موفق و انتخاب بهتر بین IPv4/IPv6 به پیدا کردن و بازیابی مسیر کمک می‌کنند.
- مشکل تایپ، پاک‌کردن و چسباندن متن در کادرهای جدید TLS/ECH اصلاح شد.
- کتابخانهٔ C++ مورد نیاز هسته در همهٔ معماری‌ها بسته‌بندی می‌شود؛ خطای `libc++_shared.so not found` رفع شد و وابستگی‌های APKها و باندل پیش از انتشار بررسی می‌شوند.

## English

Upgrade the embedded Aether core to **2.3.0**, with ECH for H2/H3, WARP registration and the outer WOM tunnel. Automatic can now try H2+ECH. Advanced Traffic settings expose the ECH resolver/domain, TLS 1.2 ciphers, key groups, GREASE and registration address.

- Add Verified edges discovery, eight validated gateway records and improved IPv4/IPv6 connection selection.
- Fix text input reverting during asynchronous saves in the new TLS/ECH fields.
- Package the matching C++ runtime for every ABI and verify native dependency closure in split/universal APKs and the release bundle.
- Retain Android socket protection, stored identity compatibility and MASQUE certificate pinning.

Local validation passed 486 engine tests, 13 bridge tests, 292 Android unit tests and eight Android emulator UI tests, plus formatting, clippy, Android lint and preview artifact verification. Six live-network tests were disabled; physical-device tunnel and restrictive-network acceptance have not been completed. The release workflow repeats native/Android tests, release lint, signed builds and artifact verification before publishing.

Choose `arm64-v8a` for most recent phones, `armeabi-v7a` for 32-bit devices, `x86_64` for compatible emulators, or `universal` when unsure. The `.aab` is for store distribution. `SHA256SUMS` covers the published APKs and bundle.
