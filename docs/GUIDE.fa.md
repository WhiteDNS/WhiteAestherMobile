# راهنمای WhiteAesther

راهنمای کامل استفاده از اپ، و اینکه وقتی وصل نمی‌شه چه کارهایی می‌تونی امتحان کنی.

---

## ۱. نصب

از [آخرین نسخه](https://github.com/WhiteDNS/WhiteAestherMobile/releases/latest) فایل مناسب گوشیت رو بگیر:

| فایل | برای کی |
| --- | --- |
| **arm64-v8a** | تقریباً همه گوشی‌های ۲۰۱۷ به بعد — **از این شروع کن** |
| armeabi-v7a | گوشی‌های قدیمی‌تر یا اقتصادی ۳۲ بیتی |
| universal | اگه مطمئن نیستی. همه‌جا کار می‌کنه ولی حجمش سه برابره |
| x86_64 | شبیه‌ساز |
| `.aab` | فقط برای آپلود در گوگل‌پلی — به درد نصب نمی‌خوره |

اندروید هشدار می‌ده که داری از بیرون فروشگاه نصب می‌کنی. این طبیعیه.

---

## ۲. اولین اجرا — سه تا نکته

### الف) گزینه Coverage رو روی «Whole device» بذار

توی تب **Traffic**. این حالت پیش‌فرضه و همون چیزیه که اکثر آدم‌ها می‌خوان: **همه اپ‌های گوشی** از تونل رد می‌شن.

> ⚠️ حالت **Proxy only** خودش هیچی رو رد نمی‌کنه! فقط یه پروکسی محلی روی `127.0.0.1:1819` باز می‌کنه و تا وقتی یه اپ رو دستی به اون وصل نکنی، هیچ ترافیکی از تونل رد نمی‌شه. اگه اشتباهی این حالت رو بزنی، به‌نظر می‌رسه وصل شده ولی عملاً هیچ اتفاقی نیفتاده.

### ب) پروفایل رو روی «Adaptive» بذار

توی تب **Routes**. این پروفایل تعادل بین سرعت اتصال و تلاش برای پیدا کردن راه رو نگه می‌داره.

### ج) اجازه اجرا در پس‌زمینه رو بده

توی تب **Settings**، اگه اندروید هنوز اجازه داره اپ رو بخوابونه، یه کارت می‌بینی که ازت اجازه می‌خواد. **حتماً بده** — وگرنه به‌محض خاموش شدن صفحه، اتصال قطع می‌شه. بعضی برندها (مخصوصاً سامسونگ و شیائومی) توی این کار خیلی سخت‌گیرن.

---

## ۳. صفحه‌ها چی‌کار می‌کنن

| تب | چی توشه |
| --- | --- |
| **Home** | فقط وضعیت. دکمه اتصال، اینکه الان چه خبره، و اطلاعات زنده. هیچ تنظیمی اینجا نیست. |
| **Routes** | *چطور* وصل می‌شه: پروفایل، اند‌پوینت، پروتکل، عمق جستجو |
| **Traffic** | *چی* از تونل رد می‌شه: پوشش، آدرس‌ها، مبهم‌سازی، پورت |
| **Settings** | خود اپ: تم، هویت، لاگ‌ها، درباره |

### رنگ دکمه اتصال چی می‌گه

| رنگ | یعنی |
| --- | --- |
| خاکستری | وصل نیست، آماده‌ست |
| **زرد/نارنجی** با فلش چرخان | داره دنبال راه می‌گرده |
| **سبز** | وصله، ترافیک محافظت می‌شه |
| **قرمز** | نتونست وصل بشه |

**اون خط خاکستری کوچیک زیر متن بزرگ، پیغام خود موتوره.** مهم‌ترین چیز برای فهمیدن مشکله — همیشه اول اونو بخون.

---

## ۴. وقتی وصل نمی‌شه

این‌ها رو **به همین ترتیب** امتحان کن. بعد از هر تغییر، یه بار قطع و وصل کن.

### قدم ۱ — پروتکل رو عوض کن (مهم‌ترین قدم)

**Routes** → **Advanced** → **Preferred transport**

| گزینه | کِی |
| --- | --- |
| **MASQUE over HTTP/3** | پیش‌فرض. روی UDP کار می‌کنه. سریع‌تره. |
| **MASQUE over HTTP/2** | روی TCP کار می‌کنه. **وقتی UDP بسته باشه، فقط این جواب می‌ده.** |

> 📌 **مورد همراه اول:** روی این اپراتور مدتیه QUIC (یعنی UDP) کاملاً بسته شده. یعنی H3 اصلاً وصل نمی‌شه و باید H2 استفاده کنی.
>
> از نسخه **۱.۰.۲** به بعد اپ خودش این کار رو می‌کنه: اگه یه پروتکل جواب نده، تلاش بعدی رو خودکار با اون یکی می‌زنه. توی خط وضعیت می‌بینی: `retry 2 of 8 on H2`

### قدم ۲ — دست‌دادن TLS رو تیکه‌تیکه کن

**Traffic** → **Advanced** → **Split the TLS handshake** → روشن

این مهم‌ترین گزینه برای شبکه‌های فیلترشده‌ست. سیستم فیلترینگ معمولاً فقط **تیکه اول** بسته رو می‌خونه تا ببینه داری به کجا وصل می‌شی. وقتی بسته تیکه‌تیکه فرستاده بشه، نمی‌تونه بخونه.

اگه با H2 وصل می‌شی ولی خیلی کنده یا وسط کار قطع می‌شه، **این گزینه رو حتماً امتحان کن**.

### قدم ۳ — پروفایل رو عوض کن

**Routes** → **Profile**

| پروفایل | برای چی |
| --- | --- |
| **Adaptive** | حالت عادی |
| **Patchy signal** | دیتای موبایل که مدام قطع می‌شه — سخت‌تر می‌گرده |
| **Strict network** | وای‌فای اداره یا دانشگاه که خیلی چیزها رو می‌بنده — آروم‌تر و بی‌سروصداتر می‌گرده، ولی کندتره |
| **Manual** | خودت همه‌چی رو تنظیم می‌کنی |

### قدم ۴ — IPv6 رو خاموش کن

**Traffic** → **Addresses** → **IPv4 only**

روی خیلی از شبکه‌های موبایل ایران IPv6 خراب یا نیمه‌کاره‌ست و باعث می‌شه اتصال معطل بمونه.

### قدم ۵ — مبهم‌سازی رو تنظیم کن

**Traffic** → **Advanced** → **Obfuscation**

| گزینه | یعنی |
| --- | --- |
| **Firewall** | پیش‌فرض |
| **Aggressive** | پدینگ سنگین‌تر، برای شبکه‌های سخت‌گیرتر |
| **Off** | بدون مبهم‌سازی — سریع‌تر ولی راحت‌تر بلاک می‌شه |

> 💡 اگه با **Split the TLS handshake** مشکلت حل شد، حتماً **Off** رو هم امتحان کن. ممکنه اون پدینگ اضافه فقط داشته سرعتت رو می‌گرفته و دیگه لازمش نداشته باشی.

### قدم ۶ — یه اند‌پوینت مشخص بده

**Routes** → **Endpoint** → **Specific address**

اول دکمه **Find endpoints** رو بزن تا اپ خودش بگرده. هر آدرسی که پیدا کرد رو می‌تونی بزنی تا انتخاب بشه.

> ⚠️ **Fall back automatically** رو روشن نگه دار. اگه خاموشش کنی و اون آدرس کار نکنه، اپ اصلاً وصل نمی‌شه به‌جای اینکه دنبال یکی دیگه بگرده.
>
> اگه دیدی آدرسی که انتخاب کردی با چیزی که توی Home نوشته فرق داره، یعنی اون آدرس کار نکرده و اپ خودش یکی دیگه پیدا کرده — کارت روی صفحه Home هم اینو بهت می‌گه.

---

## ۵. اگه هیچ‌کدوم جواب نداد

اپ حالا **۸ بار** با فاصله‌های بیشتر تلاش می‌کنه (۳ ثانیه، ۶، ۱۲، ۲۴، ۴۸، بعد هر دقیقه) و بعد متوقف می‌شه. یعنی دیگه بی‌نهایت نمی‌چرخه و باتری نمی‌خوره.

| پیغامی که می‌بینی | یعنی |
| --- | --- |
| `retry 3 of 8 on H2 in 12s` | یه راه جواب نداد، داره یکی دیگه رو امتحان می‌کنه. عادیه. |
| `Stopped after 8 attempts` | روی این شبکه هیچی جواب نداد |
| `custom endpoint ... failed MASQUE validation` | آدرسی که خودت دادی در دسترس نیست |
| `TLSV1_ALERT_ACCESS_DENIED` | سرور دست‌دادن رو رد کرد |

## ۶. گزارش مشکل

**Settings** → **Diagnostics & logs**

۱. **Detail level** رو بذار روی **Verbose**
۲. مشکل رو دوباره ایجاد کن (سعی کن وصل بشی)
۳. برگرد به همین صفحه و پایین برو

قبل از ارسال، **دقیقاً متنی که فرستاده می‌شه** رو بهت نشون می‌ده. می‌تونی انتخاب کنی چی توش باشه، و گزینه **مخفی کردن IP‌ها** پیش‌فرض روشنه.

بعد **Send** رو بزن — منوی اشتراک‌گذاری خود گوشیت باز می‌شه و خودت انتخاب می‌کنی کجا بفرستی. **هیچی بدون اجازه‌ات از گوشیت بیرون نمی‌ره.**

گزارش خودش می‌نویسه با چه تنظیماتی وصل شدی، پس لازم نیست جدا توضیح بدی.

---

## ۷. سوالات رایج

**اولین اتصال چقدر طول می‌کشه؟**
معمولاً چند ثانیه. روی شبکه‌های سخت‌گیر ممکنه تا یکی دو دقیقه هم بشه چون چند تا راه رو امتحان می‌کنه.

**چرا کانکت شدم ولی اینترنتم رد نمی‌شه؟**
احتمالاً **Coverage** روی **Proxy only** ــه. برو **Traffic** و بذارش روی **Whole device**.

**با صفحه خاموش قطع می‌شه.**
برو **Settings** و اجازه اجرا در پس‌زمینه رو بده. اگه کارت رو نمی‌بینی یعنی اجازه رو قبلاً دادی؛ اون‌وقت باید توی تنظیمات باتری خود گوشی هم اپ رو از حالت بهینه‌سازی دربیاری.

**تم روشن داره؟**
بله. **Settings** → **Appearance** → System / Light / Dark.

**نسخه اپ رو کجا ببینم؟**
**Settings** → **About**. توی گزارش تشخیصی هم خودکار هست.
