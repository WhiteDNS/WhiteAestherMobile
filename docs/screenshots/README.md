# Screenshots

Device captures used at the top of the repository README.

Save them here with these exact names, then the placeholder comment in
`README.md` is replaced with the image row:

| File | Screen |
| --- | --- |
| `home-connected.png` | Home, connected, showing the live values |
| `routes.png` | Routes, with the profile cards |
| `endpoint.png` | Routes → Endpoint, after a scan |
| `diagnostics.png` | Settings → Diagnostics *(optional)* |

Take them on a real device, not the prototype in `design/`. The prototype shows
values the app deliberately does not — an early draft had a transport race and a
latency sparkline that were dropped because the engine reports neither, and
publishing those as screenshots would advertise features that do not exist.

Portrait, and crop out the status bar if it shows anything personal.
