# Announcement artwork and text

Images posted alongside a release, kept here so a later post can reuse or
revise one rather than starting from a blank canvas.

Ready-to-copy post text is kept here alongside the artwork.

Nothing here ships in the app. It is not referenced by any layout or manifest,
and the build does not read this directory.

- `telegram-guide-poster.png` — the guide poster for the Telegram channel.
- `telegram-aether-2.3-guide.fa.txt` — Persian tutorial for the TLS controls,
  WARP registration address, ECH and Verified edges in version 1.12.0.
